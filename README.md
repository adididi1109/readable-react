# ReadAble – React Learning Tasks App

## About the Project
ReadAble is a dyslexia-friendly learning task management application built with React.

## Features
- Create new learning tasks
- Read and display tasks
- Edit existing tasks
- Delete tasks
- Search tasks
- Filter tasks by status
- Save tasks using localStorage

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Vite
- Git and GitHub

## React Concepts
- Functional Components
- Props
- useState
- useEffect
- Array map()
- CRUD Operations
- localStorage

## Installation

```bash
npm install
npm run dev
```
